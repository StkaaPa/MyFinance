# MyFinance

Aplicação web pessoal para acompanhamento das finanças pessoais.

## Objetivo

A MyFinance permite registar e consultar uma fotografia mensal das finanças pessoais, incluindo:

- Receitas
- Despesas
- Contas
- Investimentos
- Património
- Fundo de emergência

A aplicação permitirá consultar o histórico mensal e a evolução anual das finanças.

## Tecnologias

- HTML
- CSS
- JavaScript
- Python
- PostgreSQL
